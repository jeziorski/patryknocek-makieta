# Landing VSL Patryk Nocek: makieta do podglądu

Makieta landingu „film > formularz” (optymalizacja projektów deweloperskich). Podgląd dla klienta, nie strona produkcyjna.
Strony mają `noindex`, a `robots.txt` blokuje roboty. Docelowo WordPress (GLAI, Fluent Forms, wideo w Bunny Stream).

Projekt i wdrożenie: Webly Mate, weblymate.com
